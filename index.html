关于这个 Demo：哪些是真实结果，哪些是预置内容
三个规定测试案例（观点A、观点B、临时查询）展示的拆解结果、证据匹配、核验结论、 修改建议，均由实际设计的核验流水线 Prompt（声明拆解 → 证据匹配 → 逐条核验 → 结果汇总） 驱动大模型逐条对照 6 份材料原文推理得出，不是随意编造或简单的关键词硬编码。 受限于当前 Demo 运行环境无法联网调用真实 API，这些结果被固化缓存在本页面中展示， 而不是在页面加载时实时请求模型。
完整的 Prompt 设计与可实际调用 Anthropic API 的 Python 流水线代码一并提交， 接入真实 API Key 后可对任意新观点重跑同一套逻辑、产出格式完全相同的新结果 （见设计文档"AI 应用方式"一节）。
下方"对任意新观点试试看"输入框是真实可交互的，但因为同样原因未接入实时模型调用， 提交后会如实提示这一点，而不会伪造一份看起来真实的核验结果。
